プライバシーポリシー

本ページは、アプリケーション「SMZ AutoPilot」(以下「本アプリ」)におけるプライバシーポリシーです。

1. 取得する情報

本アプリは、Instagram/Facebook Graph API を通じて、運営者自身が管理する Instagram/Facebook アカウントの 投稿データ、コメントデータ、およびインサイト(分析)データのみを取得・処理します。 第三者のアカウント情報を取得することはありません。

2. 情報の利用目的

取得したデータは、投稿の自動化および分析目的にのみ利用します。 取得したデータを第三者に販売、貸与、または共有することは一切ありません。

3. データの保管と管理

取得したデータは本アプリの運営に必要な範囲でのみ保管し、適切に管理します。
