# タートルズ・トレーディングシステム インジケーター

リチャード・デニスの「タートル流トレーディング規則」をもとにした、MT5(MetaTrader 5)と
TradingView(Pine Script v5)向けのインジケーターです。自動発注は行わず、ブレイクアウト・
追加(ピラミッディング)・ストップ・撤退のタイミングと推奨ロットを画面に表示する
「シグナル・ダッシュボード」として動作します。

## 構成

```
タートルズ/
  MT5/Turtle_Trading_System.mq5          # MetaTrader 5用カスタムインジケーター
  TradingView/turtle_trading_system.pine # TradingView用 Pine Script v5
  README.md
```

## 実装しているルール

- **N(ボラティリティ)**: `N = (19×前日N + 当日TR) / 20`(ATR(20)と同一のWilder平滑化)
- **エントリー**
  - System1: 過去20日高値/安値のブレイクで新規。直前のブレイクが勝ちトレードなら次のシグナルはスキップ(オプションでON/OFF可)
  - System2: 過去55日高値/安値のブレイクで新規。勝敗にかかわらず全シグナルを採用
- **追加(ピラミッディング)**: 含み益方向へ0.5N進むごとに1ユニット追加、最大ユニット数まで(初期設定3、原典は4)
- **ストップ**: 初期ストップは2N。追加のたびに最新ユニットから2N離れた水準まで全体ストップを引き上げ
- **撤退**: System1は10日逆抜け、System2は20日逆抜けで全決済(ストップ到達時も同様)
- **ロット計算**: `ロット = (口座残高 × 1ユニットのリスク%) / (N × 1ロットあたりの価格1単位の損益)`
  でN(ボラティリティ)に応じて毎回自動計算(固定ロットにしない)

これらはあくまで「シグナルの可視化」であり、実際のポジション管理(建玉数・約定価格)を
ブローカーから読み取っているわけではありません。インジケーター内部でシグナルに基づき
仮想的にポジションを追跡しているため、実際の裁量トレードとズレが生じたら手動で状況を
確認してください。

## MT5への導入方法

1. `MT5/Turtle_Trading_System.mq5` を MetaTrader 5 の `MQL5/Indicators/` フォルダにコピー
   (MT5の「ファイル」→「データフォルダを開く」から `MQL5/Indicators/` を開いてコピー)
2. MetaEditorで開き、コンパイル(F7)。エラーが出ないことを確認
3. MT5の「ナビゲーター」→「インジケーター」を更新し、チャートへドラッグ&ドロップ
4. 入力パラメータ(下記)を確認・調整して「OK」

MT5版は `AccountInfoDouble` / `SymbolInfoDouble` から実際の口座残高・銘柄の1ロット価値を
自動取得できます(`口座残高を手動指定する` をOFFにすると自動残高を使用)。

## TradingViewへの導入方法

1. TradingViewでチャートを開き、下部の「Pineエディタ」タブを開く
2. 新規スクリプトを作成し、`TradingView/turtle_trading_system.pine` の内容を貼り付け
3. 「チャートに追加」をクリック
4. インジケーター右上の歯車アイコンから入力パラメータを調整

TradingViewは実口座残高を取得できないため、「口座残高」「1ロットが価格1動いた時の損益」
は手入力してください(GOLD/XAUUSDの標準100ozロットなら100を目安に、実際はブローカーの
仕様で確認してください)。

## 主な入力パラメータ

| パラメータ | 説明 | 初期値 |
|---|---|---|
| System1 / System2 使用 | どちらのブレイク方式を使うか | System1のみ ON |
| 勝敗フィルタ(System1) | 直前が勝ちなら次のブレイクをスキップ | ON |
| Nの期間 | ATR/Nの計算期間 | 20 |
| 口座残高 | リスク計算のベース | 100,950 |
| 1ユニットあたりリスク% | 1ユニットの許容損失(%残高) | 0.25% |
| 最大ユニット数 | ピラミッディングの上限(1〜4) | 3 |
| 1ロットあたりの価格1単位の損益 | ロット逆算に使用(TradingViewのみ手入力) | 100 |
| 1日の最大許容損失 | ダッシュボードの参考表示 | 1,000 |

## GOLD向け推奨設定(縮小版)

原典の「1ユニット＝1N動いたとき資金の1%」はプロップ口座には大きすぎるため、下記を初期値としています。

- 判断足: 日足
- エントリー: System1(20日ブレイク)のみ
- 初回リスク: 口座残高の0.25%
- 最大ユニット数: 3(1系列の最大損失 約0.75%)
- 負けているポジションへの追加は行わない(インジケーターの状態機械上も未実装)
